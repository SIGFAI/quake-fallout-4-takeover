# Credits: Fallout 4 Takeover (a Quake mod)

All new art and sound were generated for this mod with fal (um fal): nano-banana-2 concept images, Trellis 2
image-to-3D models, sound effects. Original creations, nothing ripped from any game.

- Deathclaw, Super Mutant, Mr. Handy, Radroach, Fat Man bomb models: generated (fal-ai trellis-2), converted with the kit's glb2mdl.
- Bottle cap, Stimpak, Nuka-Cola bottle, Vault Kid thumbs-up, mushroom cloud sprites: generated (nano-banana-2).
- Sounds (geiger click, deathclaw roar, flame whoosh, nuke boom, level-up jingle, caps clink, mutant roar, roach screech, robot voice): generated (fal sfx).
- Base game: LibreQuake (BSD-3 art, GPLv2 code) by lavenderdotpet and contributors; engine Ironwail 0.8.2 (GPLv2); QuakeC 1.06 by id Software (GPLv2).
- Fallout is a trademark of Bethesda; this is an unofficial fan mashup with original assets.
