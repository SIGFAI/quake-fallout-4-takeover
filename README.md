# Fallout 4 Takeover

**Quake** × Fallout 4 · visual · idea by the team

Bring Fallout 4 into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I dropped Fallout 4 into Quake: Deathclaws, Super Mutants, caps and a Fat Man nuke. The Vault Kid thumbs-up mid-slaughter gets me every time.

## Install

Copy the mod folder into your Quake folder (next to id1) as "sigf", then start Quake with the argument -game sigf and load the map lq_e0m1 (needs LibreQuake data and the Ironwail engine). Fire the rocket launcher for the Fat Man nuke.
